# Cursor 汉化操作指南（适配 3.28.7+ / v1.3.1）

> 项目：https://github.com/baishi1114010/cursor-i18n-zh  
> 本机路径：`~/Projects/cursor-i18n-zh`

---

## 一、重要提醒

1. **汉化前必须完全退出 Cursor**（Mac：`Cmd + Q`；Windows：任务管理器结束所有 `Cursor.exe`）
2. Cursor **大版本更新后**需重新汉化
3. 若汉化后**白屏/打不开**：先执行「恢复英文」，不要反复 localize
4. v1.3.1 起已修复短词误替换导致的白屏问题

---

## 二、日常一键汉化（推荐）

### Mac

```bash
# 1. 进入项目
cd ~/Projects/cursor-i18n-zh

# 2. 确认 Cursor 已退出
node index.js status
# 应显示：Cursor 运行: 否 ✅

# 3. 一键汉化
node index.js localize

# 4. 重新打开 Cursor，检查 Settings 是否中文
```

### Windows

```powershell
# 1. 进入汉化包目录（按你的实际路径改）
cd D:\安装程序\cursor-i18n-zh

# 2. 任务管理器结束所有 Cursor.exe

# 3. 管理员 PowerShell 执行

# 默认安装路径：
node index.js localize

# 自定义安装路径（如 D 盘）：
node index.js localize -p "D:\software\cursor\resources\app"

# 4. 重启 Cursor
```

**Windows 路径自检：**

```powershell
Test-Path "$env:LOCALAPPDATA\Programs\cursor\resources\app\product.json"
# True = 可用默认 localize
# False = 必须用 -p 指定到含 product.json 的 resources\app
```

## 三、白屏急救（优先做）

界面打不开 / 白屏时：

```bash
cd ~/Projects/cursor-i18n-zh   # Windows 则 cd 到你的项目目录

# 确保 Cursor 已完全退出
node index.js restore
```

看到 `🎉 已恢复英文原版` 后，重新打开 Cursor。

仍打不开时：

1. 从官网重装 Cursor  
2. 再考虑重新汉化（用本仓库 **v1.3.1+**）

---

## 四、常用命令

| 命令 | 作用 |
|------|------|
| `node index.js localize` | 一键汉化 |
| `node index.js restore` | 恢复英文原版 |
| `node index.js status` | 查看版本 / 路径 / 是否已汉化 |
| `node index.js locale` | 仅配置 VS Code 中文语言包 |
| `node index.js help` | 帮助 |
| `node index.js localize -p "路径"` | 指定 Cursor 安装目录（Windows 常用） |
| `npm run audit` | 自检优先词条覆盖率 |

---

## 五、更新 Cursor 后的正确流程

```text
1. Cursor 自动/手动更新完成
2. Cmd+Q / 结束进程，完全退出
3. cd 到汉化项目目录
4. （可选）git pull 拉取最新汉化包
5. node index.js localize
6. 重新打开 Cursor 验收
```

若更新后汉化包过旧、再次白屏 → 先 `restore`，再升级汉化工具到最新版后重试。

## 六、验收清单

打开 Cursor Settings，抽查：

- [ ] 软件能正常打开（非白屏）
- [ ] 侧栏：通用 / 账号 / 外观 / 智能体 等为中文
- [ ] Glass 主页常见按钮为中文
- [ ] 品牌名保留英文属正常（MCP、Composer、Pro+、GitHub 等）

## 八、故障速查

| 现象 | 处理 |
|------|------|
| 白屏 / 打不开 | `node index.js restore` → 重启 |
| 找不到安装目录 | Windows 用 `-p` 指到 `resources\app` |
| 权限不足 | Mac 输密码 / Windows 管理员 PowerShell |
| 更新后又变英文 | 退出后重新 `localize` |
| 菜单 File/Edit 仍英文 | 扩展市场安装 Chinese Language Pack |
